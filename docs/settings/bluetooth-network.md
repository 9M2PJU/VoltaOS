# Network and Bluetooth

## Network (Wi-Fi)

- The current network ("Connected · signal …") with **Disconnect**.
- **Available networks**: the list, with **Refresh**; tap a network, enter the **password** and press **Connect**.
- If there is no adapter, "No Wi-Fi adapter found" appears.

It uses NetworkManager (`network-manager`).

## Bluetooth

- **Bluetooth** switch: turning it off disconnects all devices.
- **Paired devices**: tap to connect; **Forget** to remove.
- **Nearby devices** and **Scan**: to add a phone or something else. First make sure it is
  **on and discoverable**. Tap it and use **Pair**: a code appears that you must **check** (or
  type) on the device, and the **Confirm** button.
- Wireless controllers pair if they support Bluetooth Classic.
- The device type (phone, headphones, speaker, GPS…) is recognized from the icon.

The paired phone enables [Phone](../app/phone.md), [Messages](../app/phone.md#messages)
and [music from the phone](../app/bluetooth.md).
